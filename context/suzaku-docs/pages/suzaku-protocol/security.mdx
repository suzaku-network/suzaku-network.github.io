# Suzaku Security

## Audits

### Suzaku Core Contracts

The Suzaku Core contracts have undergone comprehensive security audits. The audit reports are available in the [audit](https://github.com/suzaku-network/suzaku-core/tree/main/audit) folder of the repository:

- **Cyfrin** - July 2025 ([Report](https://github.com/suzaku-network/suzaku-core/blob/main/audit/2025-07-07-cyfrin-suzaku-final-v2.0.pdf))
- **Omnicia** - May 2025 ([Report](https://github.com/suzaku-network/suzaku-core/blob/main/audit/Suzaku-Network-%20Core-Contracts-Security-Audit-Audit-Report.pdf))
- **Octane** - Core contracts are continuously scanned by [Octane Security](https://www.octane.security/) for new vulnerabilities

### Suzaku Contracts Library

The Suzaku Contracts Library components have been audited by multiple security firms. The audit reports are available in the [audits](https://github.com/suzaku-network/suzaku-contracts-library/tree/main/audits) folder:

#### Validator Manager
- **Omniscia** - May 2025 ([Report](https://github.com/suzaku-network/suzaku-contracts-library/blob/main/audits/ValidatorManager/05_09_2025_SuzakuNetwork_ValidatorManager_Omniscia_SecurityAudit.pdf))
- **Cyfrin** - October 2025 ([Report](https://github.com/suzaku-network/suzaku-contracts-library/blob/main/audits/ValidatorManager/2025-10-10-cyfrin-suzaku-balancer-validator-v2.0.pdf))
- **Octane** - All the Suzaku library contracts are continuously scanned by [Octane Security](https://www.octane.security/) for new vulnerabilities

### Suzaku Restaking Collateral contracts

[suzaku-network/collateral](https://github.com/suzaku-network/collateral) is a fork of [symbiotic/collateral](https://github.com/symbioticfi/collateral) and the contracts deployed are exactly the same as the contracts that were audited for Symbiotic.

The audits of the Symbiotic Collateral contracts are available in the [audits](https://github.com/symbioticfi/collateral/tree/main/audits) folder of the repository and were performed by Statemind and ChainSecurity.

## Continuous Security

Suzaku Protocol maintains ongoing security through continuous auditing with **Octane Security**. This ensures that all protocol updates and new features undergo rigorous security review before deployment.
