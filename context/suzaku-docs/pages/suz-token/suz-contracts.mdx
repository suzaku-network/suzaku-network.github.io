# SUZ Token Contracts

## SUZ Token

### SUZ ERC-20

The SUZ token lives on the Avalanche C-Chain at address [0x451532F1C9eb7E4Dc2d493dB52b682C0Acf6F5EF](https://snowscan.xyz/address/0x451532F1C9eb7E4Dc2d493dB52b682C0Acf6F5EF).

### sSUZ

sSUZ is an LST (Liquid Staking Token) powered by a [Milk Vault](https://yieldyak.com/avalanche/milk/) (in partnership with [Yield Yak](https://yieldyak.com)). It lives on the Avalanche C-Chain at address [0x72Ab674eC8FB2b2626Cf48131Fe34fC95075D9b5](https://snowscan.xyz/address/0x72Ab674eC8FB2b2626Cf48131Fe34fC95075D9b5).
