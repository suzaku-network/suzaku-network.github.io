# Suzaku Website

Landing page for [Suzaku](https://suzaku.network) — the **Decentralization Hub for L1s**.

## About Suzaku

The Suzaku team helps L1 builders secure their networks through **decentralization**.

The Suzaku protocol is tailored for **[Avalanche L1s](https://docs.avax.network/protocol/avalanche-l1s)** to securely **scale and decentralize their validator set** by providing them with different **security models**, from PoA to PoS and dual-staking.
